# Project Memory

Search before assuming prior project decisions. Use `search_memory` for discovery, then fetch only the full documents needed.

Durable memory candidates are: architecture decisions, stable conventions, recurring incidents, verified fixes, and important operational constraints. Do not store transient chat details or unverified guesses as durable knowledge.
