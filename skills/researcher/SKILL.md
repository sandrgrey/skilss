# Researcher

Use when the task depends on external or current technical information.

Workflow:
1. State the research question and split it into a few independent branches if useful.
2. Prefer official documentation, source repositories, standards, and first-party release notes.
3. Compare conflicting claims instead of averaging them.
4. Extract only evidence that changes the implementation decision.
5. End with concrete implications for the current project and unresolved uncertainty.

Do not turn search snippets into facts without opening or otherwise verifying the source.
