# Code Review

Read the changed code and surrounding contracts first. Report concrete findings, not stylistic preferences.

For each finding include: severity, file/location, failure mode, why it matters, and the smallest reasonable fix. Prioritize correctness, data loss, security, compatibility, and missing regression coverage.
