# Sandr Dev Stack

Sandr Dev Stack is a lightweight local control layer for coding agents. Markdown is the canonical knowledge source, SQLite FTS5 is a disposable search index, MCP exposes read-only retrieval, LoopGuard detects repeated failure strategies, and file transactions protect configuration changes.
