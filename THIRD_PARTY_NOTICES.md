# Architectural references

- `howdeploy/kisa-stack` — MIT; portable skill/global-agent configuration patterns.
- `howdeploy/deploychan_mcp` — MIT; read-only MCP + SQLite FTS5 retrieval patterns.
- `howdeploy/ObsidianDataWeave` — MIT; Markdown-first knowledge and incremental local indexing patterns.
- `howdeploy/Xrayebator` — MIT; validated atomic mutation and exact rollback patterns.
- `howdeploy/Z.A.E.B.A.L` — architecture only. No source code copied because the reviewed repository did not contain a LICENSE file.
