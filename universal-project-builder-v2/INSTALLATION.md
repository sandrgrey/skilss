# Установка и использование

## Новый проект

1. Создайте пустую папку проекта.
2. Распакуйте содержимое `universal-project-builder-v2/` в эту папку — в корне должны лежать `AGENTS.md`, `CLAUDE.md` и `PROJECT_BRIEF.md`, а также **скрытые** каталоги `.ai/`, `.claude/`, `.agents/`.
3. Откройте `PROJECT_BRIEF.md`, заполните поля, прежде всего цель, функции, платформы и критерии приёмки.
4. Откройте **эту же папку** через Codex или Claude Code и отправьте первый запрос из `PROMPTS_RU.md`.

## Существующий проект

1. Сделайте резервную копию/commit вашего проекта.
2. Сравните уже существующие `AGENTS.md` и `CLAUDE.md` с предлагаемыми, **объедините** важные правила вместо замены.
3. Скопируйте `.ai/`, `.claude/skills/` и `.agents/skills/` так, чтобы не перезаписать одноимённые пользовательские skills.
4. Сохраните существующие конфигурации, зависимости, настройки окружения и Git без изменений.
5. Заполните `PROJECT_BRIEF.md` реальными требованиями, установите MODE `EXTEND`, `REFACTOR` или `AUDIT`.

## Проверка комплекта (необязательно)

Требуется Node.js 18+; для теста JSON module import в приложенном примере — Node.js 22+ рекомендуется.

```bash
node scripts/validate-kit.mjs
node --test .ai/references/motion-core.test.mjs
```

## FAQ

**Нужны ли все модули?** Нет. Базовые правила — постоянные; модули подключаются в зависимости от типа задания.

**Можно ли применить к Python?** Да, правила платформенно независимы. JavaScript-код `motion-core.mjs` — пример вспомогательной математики, а не обязательная зависимость для Python-проекта.

**Нужно ли добавлять библиотеки в проект для skills?** Нет, сами Markdown skills — инструкции. Реальные зависимости проекта выбираются отдельно.

**Почему нет ZIP с видео Marlin?** В пользовательском PDF оригинальные assets даны отдельной внешней ссылкой; их доступность, права использования и актуальность не проверены.

**Что делать, если агент не читает нужный модуль?** Явно попросите открыть конкретный `.ai/modules/<name>.md`. Проверьте, что `AGENTS.md`/`CLAUDE.md` находятся именно в корне открытого проекта.
