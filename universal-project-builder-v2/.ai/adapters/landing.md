# Adapter: Landing / Portfolio / Product Showcase

**Enable:** architecture + design-system. Add cinematic-engine, video-engine, 3d-engine only if brief requires their effects.

## Journeys and sections
Determine CTA first; map hero → benefits / product narrative → evidence → CTA → footer. Use semantic headings; don't invent unsupported claims about the product.

## Acceptance
- Major CTA paths behave correctly (forms, external contact, anchors).
- Loading, no-JS where applicable, media failures and fallback states are credible.
- SEO title, description, headings, social image where supplied, crawlability as needed.
- Responsive at target widths; focus order, contrast, reduced-motion, keyboard interactions checked.
- Motion enhances content rather than hiding it; the page remains useful if video is unavailable.
- Verify Lighthouse or other performance metrics where tools exist.

## Marlin option
For scroll-choreographed product showcases, use a **HYBRID** document with a self-contained fixed-stage hero. Do not scale every paragraph to illegibility. Split reference timetables and assets from structural data and functional CTAs.
