# Example brief — Marlin-inspired promo

- PROJECT_NAME: Marlin-inspired showcase
- MODE: ADAPT
- FIDELITY: INSPIRED
- PROJECT_TYPE: landing
- GOAL_AND_AUDIENCE: cinematic presentation of a marine product; user contacts sales
- CORE_USER_JOURNEYS: discover product → explore story → inspect stats → contact sales
- MUST_HAVE: scroll-driven hero, independent parallax groups, functional CTA, responsive footer, reduced-motion static mode
- SHOULD_HAVE: crossfade between two licensed short clips, card grid, accessible fallback poster
- OUT_OF_SCOPE: payments, user accounts unless explicitly provided
- REFERENCES_AND_ASSETS: Water.pdf (user-provided reference); original asset license must be checked
- DESIGN: dark theme #0b1016, accent #d8f24a, wide display typography; inspired rather than copied brand
- ANIMATION: CINEMATIC using the optional preset `.ai/references/marlin-timeline.json`
- TECH_STACK: AUTO (React/Vite can be selected if fit)
- PLATFORMS_AND_BREAKPOINTS: desktop and mobile 390/768/1024/1440
- ACCEPTANCE_CRITERIA: video/fallback; working CTA; no unreadable mobile text; scroll forward/backward; build/test evidence
- EXECUTION_MODE: PLAN_THEN_IMPLEMENT

**Important:** source PDF's 1440×810 artboard and `620vh` scroll describe the original demo, not mandatory values for every project. No media asset archive is included in this kit.
