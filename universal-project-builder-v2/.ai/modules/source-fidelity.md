# Source fidelity — EXACT / INSPIRED / CUSTOM

## Extract before implementing
Inventory materials and their origin: images, source files, design frames, brand fonts, dimensions, typography, breakpoints, motion events, asset rights, link destinations. Cite file/page or repository location in internal notes.

For a PDF containing code, preserve real code blocks and examine line wraps/hyphenated URLs introduced by PDF extraction. Prefer original machine-readable sources if supplied; don't promise copied PDF code is byte-identical.

## Mode contract
- **EXACT**: preserve verified copy, placement, palettes, typography, motion semantics, timelines and components. Do not silently 'improve' design. Mark unavoidable departures with rationale.
- **INSPIRED**: preserve core feel and mechanics; fix technical shortcomings and allow substitute assets/styles with attribution of differences.
- **CUSTOM**: use references solely as input patterns; implement the user's own product requirements.

## Evidence
Keep a reference map with: element, source frame/page, measured value, implementation location, confidence (`measured`, `reported`, `estimated`), verification result.

No assumptions that a file's narrative or advertising claims prove source ownership or production readiness. Report missing assets, licensing uncertainty and reference inconsistencies.
